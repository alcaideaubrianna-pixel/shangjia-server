# 后台安全入口

仅修改 youban-server 后端和随镜像构建的 web 后台，不修改会员端、采集或推送链路。
默认关闭，未配置时沿用原 `/admin`。无需 SQL 迁移。

## 启用

Web 角色配置以下环境变量，所有 Web 实例保持一致：

```text
YOUBAN_ADMIN_ENTRY_PATH=/<16至128位随机字母数字或_-字符>
YOUBAN_ADMIN_ENTRY_KEY=<至少32位独立随机密钥>
```

分别使用 `openssl rand -hex 24` 和 `openssl rand -hex 32` 生成随机串，不使用示例值。
需要 HTTPS、`cache.adapter: redis`。先在测试环境验证，再部署 Web；无需重启 Account、
Publish、Media 等角色。前端资源继续使用现有 `/admin/` 前缀，不需要按秘密入口重新构建。
入口或签名密钥不合法、启用时未配置 Redis，Web 会明确拒绝启动，不会静默开放后台。

访问 `https://你的域名/<入口>/#/login`。入口响应签发 12 小时有效的 Secure、HttpOnly、
SameSite=Strict Cookie；它仅证明访问过安全入口，后台仍需原有账号登录和权限校验。
未持有入口 Cookie 的 `/admin/*`（包括登录接口和静态资源）返回 404。
`/admin`、`/admin/`、`/admin/index.html`、`/login` 即使持有 Cookie 也返回 404。

安全入口页与后台响应设置 no-store、no-referrer；反向代理/CDN 必须遵守缓存响应头，
不要启用覆盖这些响应头的“缓存所有页面”规则。网关访问日志也应脱敏入口地址。
Cookie 不能跨域使用；此方案适用于当前同域、随服务构建的后台。
入口页保持原地址，登录失效通过 hash 路由返回登录页，不跳回旧 `/login`。

## 登录保护

启用安全入口时：

- 密码登录强制验证码，验证码保存共享 Redis，5 分钟过期且只能消费一次。
- `isLock=true` 仅在有效后台 Token 与登录账户一致时跳过验证码，不能匿名绕过。
- 密码／短信登录共用预算：每个来源地址 5 分钟最多 30 次，每个账号输入值
  15 分钟最多 10 次；全部尝试计数，包括成功登录。超过预算返回 429，窗口结束恢复。
- 验证码获取单独限制为每个来源地址 5 分钟 60 次。
- 计数与互斥租约共享 Redis，固定 TTL；存储故障时仅后台登录返回 503。

IP 默认取实际 TCP 对端，不信任任意 X-Forwarded-For。经 SAE 网关/CDN 代理时，
同一代理出口共享 IP 预算，这是保守策略；账号预算仍然独立。需要更高管理登录量时，
先核实可信代理链，再扩展代理白名单，不能直接信任客户端可伪造的请求头。

用户端 `/api/*`、Bot Webhook、健康检查不受此门禁或登录限流影响。
不同别名登录同一账号会分别计数，因此还需保留 IP 限流和验证码。

## 验证与回滚

本地测试覆盖：静态文件和 API 门禁、旧入口拒绝、URL 编码／大小写路径、Cookie
伪造／过期／签名轮换、多请求共享限额、Redis 故障、验证码跨实例消费及重复使用。
测试仅连接本地 HTTP 服务和 miniredis，不连接线上数据库或发送 Telegram 消息。

启用后验证安全入口登录、刷新、锁屏解锁、退出后重新登录、用户端和 Webhook。
改入口或签名密钥会使旧入口 Cookie 失效；将新入口安全地提供给管理员。
回滚时清空 `YOUBAN_ADMIN_ENTRY_PATH` 并滚动更新 Web，恢复原入口和原登录行为。
不要直接修改业务接口前缀 `router.admin.prefix` 来代替此门禁。
