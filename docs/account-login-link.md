# 租户账号登录链接

## 使用

系统后台 → 上架插件 → 账号 → 登录链接。入口由后端根据当前系统超级管理员身份显示，生成接口再次校验身份；租户管理员身份不能生成。

首次填写业务后台的站点根地址（不是 API 地址），浏览器记住该地址。若业务后台使用 Hash 路由，地址需带 `/#/`；非根路径部署需保留部署前缀。点击生成后复制链接即可。

业务前端入口为 `/auth/token-login`。凭证放 URL fragment，页面读取后立即清除；随后通过现有账号及个人信息接口校验。有效凭证加入现有多账号列表，保留原账号，并通过整页跳转清除旧页面和动态路由。无效凭证不替换、不登出原账号。

## 实现边界

- 生成接口：`POST /admin/youban_publish/publish/account/loginLink`，参数 `{ "id": 目标账号ID }`。
- 复用现有 `loginPublishAccount` / `token.Login`，返回普通账号 Token 和有效时长，不新增兑换接口。
- Token 只能获得目标账号自身权限。生成前校验目标账号、归属租户存在且启用。
- 链接可重复使用，期限及自动续期遵循正常登录会话；不是一次性短链。若关闭多端登录，生成新会话会遵循现有异地登录策略。
- 审计日志记录生成者、租户及目标账号，不记录链接或 Token。前端仅持久化站点地址；登录后 Token 进入已有多账号会话存储。

## 发布

无需 SQL 迁移。需要更新后端 Web/API 角色、系统后台 `web/` 和业务前端 `apps/web-antdv-next`。后端、两处前端均未部署时不应启用入口。

## 验证

后端：未登录及 AppApi 身份（包括 ID 与系统管理员相同的租户管理员）不能生成；非法目标参数拒绝。

业务前端：无效链接保留当前会话；有效链接保存新旧账号并清除旧 refreshToken；同账号更新凭证无重复项；入口清除 URL 凭证、拒绝 query Token、显示可恢复的失败状态。

本地未连接生产签发真实账号凭证，未替用户登录生产账号。生产端到端验收需在发布后用指定测试账号完成。
