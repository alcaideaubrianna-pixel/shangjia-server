# 频道权限熔断与恢复

同一租户、同一发布频道的最近10条不同已发送任务均因明确目标权限错误失败时暂停新推送。任务成功、其他失败或结果未知均打断连续失败。只统计进入过调度的资料发布任务，排除消息计划任务和清理阶段错误；不把媒体404、URL抓取失败、超时、限流算作权限错误。

暂停独立存储，不修改频道启用、采集或删除配置，不删除资料。创建资料频道任务时，锁定权限状态行，暂停频道返回无任务结果，不新增Job/Outbox；全部目标均暂停时，资料发布操作标记失败，不长时间显示上架中。会员到期仍由现有采集入口VIP校验停止采集。

全部目标暂停的失败投影提交后，提交入口返回明确的权限暂停错误，不能返回提交成功，也不能把这个错误从事务内部返回而回滚失败投影。部分频道暂停、仍有Job创建时继续正常提交。人工/AI接口透传原因；采集已入库资料保留，本次分发标记skipped，不反复采集；后台保存任务返回SkipRetry，避免反复保存上传；定时上架终止本次计划；全量推送终止批次；频道循环批次按实际已创建任务保存计数和游标，原子释放批次占用。资料时间循环查询排除暂停频道，领取后的竞态暂停仅延后，不记提交成功。

未发送、无Attempt且无消息证据的历史任务转为superseded，Outbox同步收口，不再周期性尝试发送。每批最多200条，已有恢复器在分布式锁下继续收敛积压。入队及获取发送锁后仍检查暂停状态。恢复时间作为分界，遗漏的旧任务即使已在Redis排队也不能恢复后自动发送；恢复后的新任务正常创建。

已终止的普通未发送任务调度记录按一个自然月保留，恢复器按批事务删除Job、Outbox和发布记录；不删除资料、媒体或采集来源。保留时间按终止时间算，后台下一轮分批清理，不是精确到秒的TTL。已有Attempt、消息证据、正在发送和结果未知任务不强制删除，继续原有对账/清理流程，发送证据不适用普通调度日志保留期。下架删除任务不受权限暂停拦截。

向频道创建账号发送机器人通知，携带“检查权限并恢复推送”按钮。通知走已有后台队列，恢复器补偿未通知记录。通知发送后写已通知标记；极端情况下发送成功后进程中断，通知可能再次送达，不保证通知消息严格仅一次。

按钮操作使用当前Telegram用户的绑定账号验证租户、归属账号与暂停代次；旧按钮不可恢复新一轮暂停。30秒内检查所有配置的推送Bot是否在频道并有发送权限，不自动添加Bot。权限检查不通过保持暂停；通过后解除暂停。未发送历史资料不会自动补投，需要主动重新上架；已有发送证据任务仍按原状态机补偿，避免直接丢弃资料/验证或重复发送。

暂停、恢复、旧worker延后任务使用同一数据库行锁/CAS保护，避免恢复后又被旧worker延后一小时；恢复时间隔离旧的失败记录。

## 部署前置条件

必须在部署代码前执行对应数据库迁移：

- PostgreSQL：addons/youban_publish/resource/sql/channel_permission_circuit.pgsql.sql
- MySQL：addons/youban_publish/resource/sql/channel_permission_circuit.sql

脚本仅新增表且可重复执行，已加入安装/升级脚本列表；发送请求不会自动建表。缺表时暂停检查返回错误，所以不能跳过迁移直接部署。回滚代码可保留此表，但旧代码不会执行权限熔断。

## 本地验证

使用127.0.0.1:35432的独立PostgreSQL事务和临时表执行真实SQL，未访问生产数据。运行：

    YOUBAN_PERMISSION_LOCAL_PG=1 go test -race ./addons/youban_publish/logic/sys -run TestTelegramPermissionCircuit -count=1 -timeout 60s

覆盖错误分类、9/10阈值、成功/其他错误中断连续失败、真实最近10条查询及恢复时间过滤、暂停范围、重复暂停、旧按钮、越权恢复、恢复Job与Outbox、恢复后旧worker不再延后任务。额外覆盖250条积压每批只终止200条、暂停期间创建入口不产生Job、下架/其他租户/未知结果/已有Attempt不被终止、恢复后旧任务仍不发送而新任务可发送、一个月前调度记录及关联日志事务清理、近期终止记录保留。外部Bot权限检查复用已有checkBotChannelMember；当前未进行真实线上恢复按钮/通知端到端验证。
