# BOT 采集管理流程文案

本文列出本次涉及的三个流程。`{...}` 为实际运行时数据；数量由后台查询，示例数字不写入程序。

## 1. 新频道首次收到消息

触发：新频道首次产生采集消息，且对应规则开启代理采集后缀。每条匹配规则各发送一条通知，频道账户关系已存在时不重复通知。沿用现有超级管理员通知接收配置。

```text
发现新的代理采集频道
频道：{频道名称}
频道 ID：{频道ID}
频道链接：{频道链接，有链接时显示，无链接时省略整行}
采集规则：{规则名称}
频道后缀：{实际生效后缀，未设置时显示“未设置”}
采集状态：默认开启
后续新采集资料将使用上述后缀，可通过下方按钮禁用采集或修改后缀。
```

底部按钮：`禁用` / `修改后缀`。

点击“禁用”先显示二次确认，确认前不修改状态：

```text
确认禁用频道采集？
频道：{频道名称}
频道 ID：{频道ID}
频道链接：{有链接时显示}

确认后不再采集该频道的新消息。已有资料、已推送消息和后缀配置保留。
```

按钮：`确认禁用` / `取消`。

点击“确认禁用”后：

```text
频道采集已禁用
频道：{频道名称}
频道 ID：{频道ID}
频道链接：{频道链接，有链接时显示，无链接时省略整行}
操作原因：管理员主动禁用采集
后续新消息将不再采集；已有资料和已推送消息保留。
```

未开启代理采集后缀的规则保留普通采集通知：

```text
发现新的 BOT 采集频道
频道：{频道名称}
频道 ID：{频道ID}
频道链接：{频道链接，有链接时显示，无链接时省略整行}
采集状态：默认开启
```

按钮：`允许采集` / `禁用`。

## 2. 修改频道后缀

点击“修改后缀”先显示确认页：

```text
确认修改频道后缀？
频道：{频道名称}
频道 ID：{频道ID}
频道链接：{有链接时显示}
当前后缀：{当前后缀}

继续后请输入新后缀，预览并再次确认保存后才会生效。
```

按钮：`确认修改` / `取消`。

点击“确认修改”后进入输入流程：

```text
修改频道后缀
频道：{频道名称}
频道 ID：{频道ID}
频道链接：{频道链接，有链接时显示，无链接时省略整行}
当前后缀：{当前后缀；无专属配置时显示规则默认后缀}

请发送新的频道后缀，例如：北京代理。
发送后会显示预览，确认保存后才生效。
发送 /cancel 取消修改。
```

输入新后缀后：

```text
确认修改频道后缀
频道：{频道名称}
新后缀：{输入内容}

保存后将开启该频道采集，后续新采集资料使用此后缀。确认保存吗？
```

按钮：`确认保存` / `取消修改`。

保存成功：

```text
频道后缀已保存
频道：{频道名称}
频道 ID：{频道ID}
频道链接：{频道链接，有链接时显示，无链接时省略整行}
新后缀：{新后缀}
采集状态：已开启
后续新采集资料将使用此后缀。
```

点击“取消修改”：

```text
已取消修改，频道采集状态和当前后缀保持不变。
```

异常提示：

- 频道失效：`频道不存在或已失效，请刷新频道列表后重试。`
- 会话失效：`频道后缀设置已失效，请重新操作。`
- 空后缀：`频道后缀不能为空，请重新输入`

## 3. 采集配置入口

路径：`采集源列表 → 选择采集源 → 采集配置`。

只有一条规则时，直接显示配置编辑页：

```text
采集配置
规则：{规则名称}
请选择要修改的配置项：
```

按钮：`删除整行（{数量}条）`、`删除文本（{数量}条）`、`文本替换（{数量}条）`、`费用清理 · 开启/关闭`、`介绍费后缀 · 开启/关闭`、`前置文案 · 开启/关闭`、`后置文案 · 开启/关闭`、`返回采集配置`、`返回资料管理`。

绑定多条规则时，保留必要的选择页：

```text
采集配置：{采集源名称}
该采集源绑定了 {数量} 条规则，请选择要配置的规则。

规则：{规则名称}
```

按钮：`修改配置 · {规则名称}` / `返回采集源`。

未绑定规则：`当前采集源未绑定专属规则，请先在后台完成配置。`
无权限：`仅租户管理员可以配置采集规则。`

规则文本配置沿用现有输入、预览、确认保存流程。频道后缀列表、详情和添加频道入口保留。

## 4. 删除频道代理资料并下架

点击“删除并下架”先查询实际资料与消息数量，显示确认页：

```text
删除频道代理资料并下架
操作原因：管理员主动删除该频道的代理资料
频道：{频道名称}
频道 ID：{频道ID}
频道链接：{频道链接，有链接时显示，无链接时省略整行}
频道后缀：{频道后缀}
关联代理资料：{数量} 条
已推送消息：{数量} 条

确认后将禁用该频道采集、删除以上代理资料及其已推送消息，并清理频道后缀和计数。此操作不可恢复。
```

按钮：`确认删除并下架` / `取消`。

确认执行时重新查询数量，在上述频道信息和数量之后显示：

```text
状态：任务已提交，该频道采集已禁用。后台正在删除上述代理资料及其已推送消息，完成后会再次通知。
```

没有关联资料时，直接完成配置清理，状态改为：

```text
状态：已完成。该频道采集已禁用，频道后缀和计数已清理，无关联代理资料或已推送消息需要删除。
```

超级管理员也会收到包含原因、频道、后缀、数量和状态的通知。

后台完成通知：

```text
频道代理资料删除成功
操作原因：管理员主动删除该频道的代理资料
频道：{频道名称}
频道 ID：{频道ID}
频道链接：{频道链接，有链接时显示，无链接时省略整行}
原频道后缀：{原后缀}
已删除代理资料：{数量} 条
已清理推送消息：{消息数量} 条
已处理推送任务：{任务数量} 条
频道采集：已禁用
频道后缀和资料计数：已清理
状态：删除并下架成功
```

成功通知在后台删除完成后发送。若 Telegram 消息删除失败，标题改为“频道代理资料删除完成（消息清理异常）”，消息数量标注为“关联已推送消息”，最后一行改为：

```text
状态：资料删除已完成；{数量} 个任务的 Telegram 消息清理失败，需进一步处理
```

消息数量与推送任务数量分别统计，不用任务数量冒充消息数量。确认页数量为实时预估，执行时可能因新消息变化。


## 采集链路修复说明

- 上架频道过滤先于新频道通知，过滤掉的频道不会提示已开启采集。
- 新频道通知进入后台队列，发送失败重试；按通知和接收人去重。
- 修改后缀的保存、取消按钮绑定会话和当前预览。旧频道、旧预览按钮失效，不影响新操作。
- 删除范围为当前账户下该来源频道的全部规则及 BOT；不删除其他账户资料或共享后缀配置。
- 删除任务保留资料、推送任务及消息数量快照，重试跳过已经删除的资料。
- 完成通知会发送给操作发起人，管理员副本遵循通知设置。一个接收人发送失败不阻止其他接收人。
- 只有关联消息全部清理后才通知删除成功。存在待删除或 BOT 无法删除的消息时，通知“频道代理资料已删除，消息清理未完成”，显示已清理、待清理、无法删除数量，并继续检查补偿结果。
- 通知重试次数耗尽后任务留在失败队列，须排查权限或送达失败后重试，不会把失败改报成功。
