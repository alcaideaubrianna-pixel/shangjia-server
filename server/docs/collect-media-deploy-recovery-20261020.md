## 代码修复

- 事件锁及账号/来源媒体并发槽使用 2 分钟租约，20 秒续期一次。
- 续期使用原锁库的 token 比较原子操作，关闭其进程级 watchdog，续期生命周期绑定当前任务 context。
- 续期失去所有权或 Redis 报错时，取消当前 I/O，不继续把未知租约当作有效执行；任务返回可重试错误。
- 正常结束停止并等待续期协程退出，再执行原 token 比较解锁。不会删除接管者的锁。
- Bot 恢复器原本已包含 downloading/pending 事件，可在短锁过期后重走原缓存流程；验证窗口、验证绑定、发布顺序不变。
- 这不是发送 Attempt 超时重发方案，不修改 Telegram 发送成功/未知结果处理。

## 发布限制

修改部署 Media 角色后生效；已有旧版本长锁不会因新版本上线自动缩短。只能在核实旧实例已退出、没有活动执行、token 未变的情况下单独释放，禁止批量删锁。原始事件历史补放是独立工作，本次尚未执行。
