# Youban Agent 生产交付约定

生产运行在腾讯云 TKE。入口和命令以 [生产排障手册](../../docs/production-debugging.md) 及 [TKE 红蓝发布手册](../../deploy/TKE.md) 为准。

1. 核对 Git 分支、工作区、变更范围与目标角色。执行精确的本地编译或专项测试，记录结果。提交、镜像构建、部署、切流和业务验收分别记录。
2. 通过现有 CI 构建待发布提交的不可变镜像。核对 TCR 摘要、当前生产版本和回滚版本。仅在获授权时执行生产发布，通过就绪、依赖、代表性业务及日志验收后再切流。
3. 只读业务排查先用 CLS、链路和精确主键。沿租户、账号、频道、资料、任务和消息逐层确认，样本须脱敏。业务修复工具先 preview，再核对租户、数量、幂等和回滚后 apply。遇到发送结果未知，先做回执对账。
4. 收尾记录时间与时区、集群/角色、变更前后版本、验证样本、影响、回滚点及待办。已提交、已构建、已切流和已通过业务验收分别给出结果。
